## Project Description
VitalsMed is a patient health monitoring system that tracks vitals (pulse, temperature) and medication adherence.

## First Sprint Features
- CRUD operations for Medications
- Login/Register functionality
- Database configuration and connection

## Running
1. Clone the repository
2. Configure `application.properties` for your MySQL
3. Run `VitalsMedApplication.java`
4. Test API endpoints using Postman
